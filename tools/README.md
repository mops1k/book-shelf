# Инструменты репозитория

Все скрипты не требуют зависимостей: только Node 20+ и `bash`. У инструментов есть и свои тесты
(встроенный раннер Node): `node --test tools/*.test.mjs` — шаблон НЕ в кавычках: Node 20 сам `*`
не разворачивает и падает с «Could not find …», раскрывать должен шелл. Фикстуры для тестов лежат
в `tools/fixtures/`.

Генератор карты репозитория (`generate-structure.mjs`) и сама карта — локальные: документация
разработчика в репозиторий не кладётся (см. `.gitignore`).

| Скрипт | Что делает | Когда запускать |
|---|---|---|
| `check-sources.mjs` | Санитарная проверка без JDK: баланс скобок (с учётом строк и комментариев), табы, CRLF, BOM, строки > 120, `TODO` без номера спринта, `Thread.sleep` в тестах, запрещённые правилами тестируемости вызовы в main-коде | Перед коммитом, в CI первой ступенью |
| `check-reachability.mjs` | Проверяет связность экранов: каждый маршрут навигации достижим не только из пустого состояния, ни один экран не пишет «Раздел в разработке» вне состояния «данных нет», каждый переход ведёт на существующий маршрут. Появился после случая, когда зелёные тесты уживались с экранами-заглушками | При правках навигации и экранов, в CI |
| `check-versions.mjs` | Проверяет, что каждая версия из `gradle/libs.versions.toml` существует в Maven Central / Google Maven / репозитории Onyx, и (с `--latest`) показывает вышедшие стабильные версии | При обновлении зависимостей, по расписанию в CI |
| `check-coverage.mjs` | Порог покрытия по модулям: читает XML-отчёты Kover по путям из `config/coverage.json`, считает строковое покрытие и возвращает 1, если модуль ниже порога. Флаги: `--warn` (показать недоборы, код 0), `--config=путь`, `--root=путь` | В CI после `koverXmlReport*`; локально после прогона тестов |
| `check-daemons.mjs` | Показывает старые демоны Gradle/Kotlin и свободную память; возвращает 1, если демон старше 30 минут или памяти меньше 1 ГБ. Флаги: `--kill` (остановить старые демоны), `--age=15` (порог в минутах) | Перед тяжёлой сборкой: иначе демоны выбирают память и прогон уходит в своп |
| `generate-test-books.mjs` | Генерирует тестовые книги (по умолчанию в `testdata/books`): кириллица в разных кодировках, серия, несколько авторов, обложка, битый файл — чтобы одна проверка охватывала все ветки разбора | Перед ручной приёмкой на устройстве, когда нужна своя библиотека |
| `generate-launcher-icons.mjs` | Раскладывает мастер-рисунок `assets/icon/bookshelf-icon-512.png` по всем иконкам лончера: силуэты `mipmap-*dpi/ic_launcher{,_round}.png` (API 24–25), передние планы `mipmap-*dpi/ic_launcher_foreground.png` (108 dp, API 26+) и адаптивные `mipmap-anydpi-v26/ic_launcher{,_round}.xml`. Вектора нет: векторной версии у рисунка не существует | После замены или правки рисунка иконки |
| `list-stubs.sh` | Печатает все маркеры `STUB(Sprint N)` со сводкой по спринтам и модулям — это рабочий бэклог | Перед планированием работ, на ревью |

```bash
node tools/check-sources.mjs --warn   # санитария исходников (--warn показывает предупреждения)
node tools/check-reachability.mjs     # все маршруты достижимы
node tools/check-versions.mjs
node tools/check-versions.mjs --latest
node tools/check-daemons.mjs          # состояние демонов и памяти
node tools/check-daemons.mjs --kill   # остановить старые демоны
node tools/generate-test-books.mjs    # тестовые книги в testdata/books
node tools/generate-launcher-icons.mjs
node tools/check-coverage.mjs        # пороги покрытия из config/coverage.json
node tools/check-coverage.mjs --warn # то же, но недоборы — предупреждение, код 0
node --test tools/*.test.mjs        # тесты самих инструментов (встроенный раннер Node)
bash tools/list-stubs.sh              # бэклог по всему проекту
bash tools/list-stubs.sh core/data    # только по модулю
```

## Чего здесь намеренно нет

* **Генератора кода для модулей.** 22 модуля добавляются руками и с обоснованием в ADR:
  автоматизация добавила бы скорости, но не дисциплины.
* **Трассировки SVG в вектор.** Рисунок иконки существует только растром: `.svg` с рабочего стола —
  обёртка вокруг встроенного PNG (ни одного `<path>`), её рендер совпадает с PNG побайтово. Настоящий
  вектор потребовал бы обводки контуров вручную или трассировки — это отдельная задача со своим
  качеством.
* **Отдельного скрипта «нет TODO без номера спринта».** Эта проверка уже живёт в
  `check-sources.mjs` и в CI; третий способ сделать то же самое — лишнее место для расхождений.

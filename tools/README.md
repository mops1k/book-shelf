# Инструменты репозитория

Все скрипты не требуют зависимостей: только Node 20+ и `bash`.

| Скрипт | Что делает | Когда запускать |
|---|---|---|
| `check-sources.mjs` | Санитарная проверка без JDK: баланс скобок (с учётом строк и комментариев), табы, CRLF, BOM, строки > 120, `TODO` без номера спринта, `Thread.sleep` в тестах, запрещённые правилами тестируемости вызовы в main-коде | Перед коммитом, в CI первой ступенью |
| `list-stubs.sh` | Печатает все маркеры `STUB(Sprint N)` со сводкой по спринтам и модулям — это рабочий бэклог (ADR-013) | Перед планированием спринта, на ревью |
| `check-versions.mjs` | Проверяет, что каждая версия из `gradle/libs.versions.toml` существует в Maven Central / Google Maven / репозитории Onyx, и (с `--latest`) показывает вышедшие стабильные версии | При обновлении зависимостей, по расписанию в CI |
| `generate-structure.mjs` | Обновляет [`../docs/structure.md`](../docs/structure.md) — карту репозитория: верхний уровень, файлы модулей, сводка заглушек. С `--check` падает, если карта устарела | После изменения структуры; `--check` — в CI |
| `generate-launcher-icons.mjs` | Генерирует PNG-иконки `mipmap-*dpi` (API 24–25, где адаптивные иконки не поддерживаются) | После изменения силуэта иконки |

```bash
node tools/check-sources.mjs --warn   # санитария исходников (--warn показывает предупреждения)
bash tools/list-stubs.sh              # бэклог по всему проекту
bash tools/list-stubs.sh core/data    # только по модулю
node tools/check-versions.mjs
node tools/check-versions.mjs --latest
node tools/generate-structure.mjs     # обновить docs/structure.md
node tools/generate-structure.mjs --check
node tools/generate-launcher-icons.mjs
```

## Чего здесь намеренно нет

* **Генератора кода для модулей.** Каркас создан один раз; дальше модули добавляются руками
  (и с обоснованием в ADR — 22 модуля уже требуют дисциплины, а не автоматизации).
* **Скрипта «проверить, что нет TODO без спринта»** — это одна строка в CI и в ревью:
  `! grep -rn --include='*.kt' -E 'TODO(?!\(Sprint)' .` (PCRE). Добавим вместе с правилом detekt,
  когда появится первый реальный код (Спринт 1).
* **Скрипта генерации битых фикстур.** `tools/make-broken-fixtures.mjs` появится в Спринте 3
  вместе с каталогом фикстур: генерировать нечего, пока нет самих фикстур.

# Откуда файл

`libarchive-sample.rar` — тестовые данные проекта [libarchive](https://github.com/libarchive/libarchive)
(`libarchive/test/test_read_format_rar.rar.uu`, распространение BSD-2-Clause). Файл хранит
несколько записей (`test.txt`, `testlink`, `testdir\test.txt`) и нужен как НАСТОЯЩИЙ RAR:
junrar архивы не создаёт, а собрать RAR по спецификации руками — значит проверять свой же
вымысел, а не формат.

Файл распакован из uu-кодирования без изменений содержимого (336 байт).
